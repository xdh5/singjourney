# 音频格式与流量

## 当前客户端

- 微信小程序：录音阶段使用 16 kHz、单声道 PCM，保存时封装成 16-bit WAV。
- App：当前请求录制 16 kHz WAV。
- Web：浏览器支持时优先保存 Opus/WebM，其次为 MP4 或 WebM。

16 kHz、单声道、16-bit WAV 的码率是 256 kbit/s，约 1.92 MB/分钟，不适合作为长期网络传输格式。

## 后续目标

| 用途 | 推荐格式 | 建议参数 | 约占用 |
|---|---|---|---|
| 分享试听 | Opus | 单声道 48 kbit/s | 约 360 KB/分钟 |
| 音准、节奏类 AI | Opus | 单声道 24–32 kbit/s | 约 180–240 KB/分钟 |
| CPP、HNR、H1-H2 等音质分析 | FLAC | 16 kHz 或更高、单声道、无损 | 随内容变化 |

不能为了流量把所有 AI 输入都压成低码率 Opus：有损压缩会改变噪声和谐波结构，影响气声与声音集中度指标。最省流量的准确方案是：普通练声上传 Opus；需要音质分析时，只额外上传 3–5 秒持续元音的 FLAC，而不是上传整段 WAV。

当前分享接口先兼容 WAV、Opus、AAC、MP3、M4A 和 WebM。客户端压缩完成后无需更改分享数据模型。
