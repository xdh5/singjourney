# 数据模型规划

## 当前使用

### `audio_assets`

统一保存音频文件元数据：用途、存储位置、格式、大小、时长、校验值和过期时间。文件本身不进入数据库。

### `recording_shares`

保存公开分享标识、临时音频、曲线数据、时长、访问次数和过期时间。匿名分享也可以工作；登录上线后可填写 `user_id`，不用重建分享表。

## 已建表、后续启用

### 账号

- `users`：平台无关的声入佳境用户。
- `auth_identities`：手机号、Apple、微信等登录身份与同一用户的绑定关系。
- `auth_sessions`：只保存登录令牌哈希，不保存明文令牌。

这样 iOS、Android、Web 和微信身份最终都映射到同一个 `user_id`。

### 录音与同步

- `recordings`：用户主动同步到云端的录音元数据和曲线。
- `audio_assets`：可选的云端录音文件。

`client_recording_id` 用于多端同步去重。本地记录默认不上传，因此不会自动占用服务器空间。

### 练声与伴奏

- `accompaniments`：默认伴奏或用户上传伴奏，音频仍通过 `audio_assets` 管理。
- `practice_sessions`：一次练声的模式、练习项目、伴奏、录音和起止时间，是打卡点阵及统计的事实来源。

### AI 测评

- `evaluations`：一次测评任务、算法版本、状态、总分和摘要。
- `evaluation_dimensions`：音准、气息表现、稳定、连贯、声音集中度等分项结果、置信度和原始指标。

分项独立成表，后续增加或删除指标时不需要修改主表；每次结果记录 `model_key` 和 `model_version`，避免算法更新后新旧结果混在一起。

## 暂不建表

会员、订单、用量计费、消息通知和社交关系尚未明确，不提前建立。等业务规则确定后再通过新的 Alembic 迁移增加。
