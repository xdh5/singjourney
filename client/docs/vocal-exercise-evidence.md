# 练声曲目证据与产品边界

本文档记录「声入佳境」练声曲目的研究依据和产品化取舍，避免将常见教学习惯误写为已被证实的医疗效果。

## 纳入原则

- 优先纳入同行评审研究中实际使用或调查频率较高的练习类型。
- 同一音型在连奏、断奏、速度、音区和音节不同时视为不同训练任务，但不重复堆叠只换名称的曲目。
- 半闭合声道练习不声称适合所有人。研究已观察到不同歌者对吸管、唇颤音和舌颤音的反应存在明显差异。
- 应用只提供教学与自我练习，不将曲目表述为声音疾病的诊断或治疗。

## 研究映射

| 产品曲目 | 研究支持的类型 | 产品化处理 |
| --- | --- | --- |
| 唇颤音、舌颤音、吸管滑音、V/Z 滑音、哼鸣 | 半闭合声道练习（SOVT） | 作为可选热身方式，不宣称单一方式最优 |
| 五音阶、八度音阶、连奏琶音、滑音 | 专业歌者常用热身模式 | 按半音移调，起始音由用户选择 |
| 单音模唱、五音阶、琶音 | 音高匹配和音准训练任务 | 未来使用目标音与实际基频的音分差比较 |
| 连奏、断奏、上行、下行、不同音区 | 不同条件会影响音高误差 | 将这些条件作为明确练习变体，不混成一个笼统曲目 |
